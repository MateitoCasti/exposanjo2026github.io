DEL PIXEL A LA PIEZA

¿Cómo funciona el proceso?

01
1. Diseño CAD

Creamos la idea tridimensional en la computadora mediante software especializado (Tinkercad, Fusion360, etc.).

02
2. Laminado (Slicing)

El software dividirá el modelo 3D en cientos de capas horizontales delgadas y generará el código de corte (G-Code).

03
3. Impresión

La máquina calienta el filamento plástico (PLA/PETG) y deposita capa por capa con extrema precisión sobre la cama de impresión.

04
4. Acabado

Se retiran soportes auxiliares, se realiza lija fina o curado para dejar la pieza lista para su uso real.
